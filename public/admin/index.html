CONFIGURATION

Settings

관리자 콘솔이 GitHub에 안전하게 쓰기 위해 필요한 설정입니다.

1. ADMIN_PASSWORD

ChatGPT/Vercel/GitHub 계정 비밀번호가 아닙니다. 이 관리자 콘솔 전용으로 직접 정하는 별도 비밀번호입니다. 계정 비밀번호를 재사용하지 마세요.

ADMIN_PASSWORD=your-strong-admin-password

2. GITHUB_TOKEN

Fine-grained personal access token을 만들고 BokEumEom/bokeum-archive 저장소의 Contents: Read and write 권한만 부여하는 것을 권장합니다.

GITHUB_TOKEN=github_pat_...

3. Optional repository settings

기본값이 이미 현재 저장소와 main 브랜치를 가리키므로 보통 설정하지 않아도 됩니다.

GITHUB_REPO=BokEumEom/bokeum-archive GITHUB_BRANCH=main

Data flow

관리자 화면 → Vercel Function → GitHub commit → Vercel 자동 재배포 → Public Archive 순서입니다. 비밀번호와 GitHub token은 클라이언트 코드에 포함되지 않습니다.
