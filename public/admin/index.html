ChatGPT Site와 명시적 프로젝트 배포 URL을 관리합니다. 실제 확인한 URL만 저장하세요.

관리자 비밀번호란?

ChatGPT/Vercel/GitHub 계정 비밀번호가 아닙니다. 이 Archive 관리자 화면 전용으로 직접 정하는 별도 비밀번호입니다. Vercel 프로젝트의 Environment Variables에 같은 값을 넣습니다.

ADMIN_PASSWORD=직접_정한_강한_비밀번호

GitHub 쓰기 권한

관리자 API가 이미지와 JSON을 repository에 저장할 때 사용하는 토큰입니다. 브라우저 코드에는 노출하지 않고 Vercel 서버 환경변수에만 둡니다.

GITHUB_TOKEN=GitHub fine-grained token (Contents: Read and write)

선택 환경변수

GITHUB_REPO=BokEumEom/bokeum-archive\nGITHUB_BRANCH=main

기본값과 같아서 보통 생략할 수 있습니다. 환경변수를 추가하거나 변경한 뒤에는 Vercel을 재배포해야 적용됩니다.
